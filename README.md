# MP2: Responsive Website Development (CO2)

**Course:** Software Development I (CSE-2340)
**Assessment:** Mini Project 2 (MP2)

## Moonbrew Café 🌙☕
*“A Little Taste of Moonlight.”*

A simple, responsive café website built with **HTML** and **Tailwind CSS** (via CDN).

## Theme and colors
A calm moonlight theme:
- **Midnight blue** (`night`) - backgrounds and cards
- **Moon cream** (`moon`) - text and highlights
- **Latte amber** (`latte`) - buttons, prices and accents

## Features
- Navigation bar (desktop menu + mobile hamburger menu)
- Content sections: Home, Our Story, Menu, Contact / Reservation
- Styled with Tailwind CSS (custom color palette, spacing, typography, gradients, glow effects)
- Responsive layout for mobile and desktop screens
- Interactive elements: mobile menu toggle, menu category filter buttons, hover effects on cards and buttons, floating moon animation, table reservation form

## How to run
Open `index.html` in any browser (internet needed for the Tailwind CDN).
